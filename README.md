# 长生 MUD · 系统赋我长生

> 一款**零依赖、单文件、双击即玩**的修仙人生模拟器。
> 40 个 ES 模块，构建时拓扑内联成一个 HTML；不联网、不装环境、不开服务器。

**▶ 在线试玩：** <https://ctgjtyc.github.io/longlife-mud/>

---

## 这是什么

你在山野间醒来，发现自己绑定了「长生系统」——寿命无限，但境界得自己一格一格熬。
从此每一次闭关、每一场厮杀、每一次结缘与结仇，都在往一条时间轴上刻字。

游戏没有终点，只有「你活成了什么样的人」：

- **修炼**：炼气 → 筑基 → 金丹 → 元婴 → 化神……寿元随境界增长，走错路也会走火入魔
- **江湖**：宗门、散修盟、魔道三方势力，声望会传染；仇敌会寻上门，故人会老会死
- **人间**：娶妻、收徒、开宗立派、 dynasty 传承，三代之后你孙子还在替你续命
- **异变**：动态事件生成器 + 每局不同的天赋开局，同一个存档也能滚出完全不同的因果
- **文字**：2712 章网文语料提炼的叙事模板，事件描述不是填空，是有语感的短篇

死了不算输——**轮回**会带着上一世的记忆重开，某些门只有死过一次才看得见。

## 3 分钟上手

1. 打开链接（或双击 `dist/longlife_mud.html`）
2. 选一个天赋开局
3. 主界面点 **「启程码道 →」**（1024 彩蛋入口，见下）
4. 想正常玩：直接选 ①隐居 / ②江湖，跟着任务面板走

存档自动写入浏览器 localStorage，6 个槽位，随时读档。

## 🎃 1024 程序员节彩蛋：码道飞升

山道旁坐着一位敲键盘的灰袍修士，自称**代码真人**。

| 环节 | 内容 |
|---|---|
| 初遇 | 「道友，可知今日是何日子？」——十月二十四，2 的十次方 |
| 论道 | 码道三境：能跑就行 → 不要动它 → 方敢言重构 |
| 试炼 | 直面 **Bug 心魔**（`FATAL: unhandled exception`），血量条带终端副行 |
| 飞升 | 诵出 `Hello, World`，解锁成就「Hello World 飞升」，弹出「编译通过：0 errors, 0 warnings」卡片 |

主线 3 分钟可通。通关后主界面卡片变成「🏆 已码道飞升 · 点击重温」。

> 彩蛋不是硬编码进引擎的——它是一个**官方模组**，和玩家自己写的模组走完全相同的注入管线。
> 官方先吃自己的狗粮。

## 模组系统（本项目的技术看点）

```js
// 任何一个模组就是这个形状，官方彩蛋也不例外
{ id, name, version, desc, author,
  content: { quests, npcs, items, monsters, achs } }
```

- **五类注入目标**：任务链 / NPC 与对话树 / 物品 / 怪物 / 成就
- **懒求值**：`modSections()` 在加载时才解析目标表，绕开模块循环依赖的 TDZ 陷阱
- **状态保持**：成就注入时保留 `got` 字段，读档不会把已解锁成就冲掉
- **幂等安装**：重复安装同一模组不会重复注入；存档登记的官方模组读档时自动恢复
- **校验与冲突检查**：`modValidate` / `modConflictCheck` 在注入前拦下非法内容

引擎为此新增了四项通用能力，全部由彩蛋需求倒逼出来：
对话 `fight` 选项、`achs` 注入目标、`reward.flags` 聚合、模组懒求值。

## 工程

```bash
python build.py           # 40 个模块 → dist/longlife_mud.html（单文件）
python build.py --check   # 门禁：模块数 + 174 个关键函数是否齐全
python build_check.py     # 每日门禁
node test/run.mjs         # 回归套件：432 断言
```

设计约束：
- **零运行时依赖**——只有 HTML + JS，没有任何 npm 包
- **单文件产物**——`dist/longlife_mud.html` 约 1.2 MB，可直接邮件发送
- **有界内存**——日志环形缓冲上限 1000 条，长会话不涨内存
- **移动端可用**——360 px 视口无横向滚动，功能收进底部抽屉

```
js/            26 个运行时模块（core / fight / quest / modloader / …）
js/data/       14 个数据表（怪物 / 物品 / 功法 / NPC / 官方模组 / …）
test/run.mjs   回归套件（含蒙特卡洛战斗仿真）
dist/          构建产物
docs/          GitHub Pages 发布目录 + 验收截图
```

## 关于 AI 协作

这个项目的研发方式是它自己的一部分：

- **WorkBuddy** —— 代码审计、数值仿真、彩蛋体验设计（UI 设计规范、「3 分钟全链」指标由它出具）
- **GLM / ZCode** —— 功能实现与修复，按设计规范落地
- 两端通过文件化调度台交接任务，每次交付都有构建门禁与回归报告兜底

彩蛋里那句「祖传代码，动一行，崩十里」，是写给我们自己的。
