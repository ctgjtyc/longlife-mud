## 一、项目介绍

**一句话定位**：一款以「长生不死」为核心的文字修仙 MUD 游戏——主角天生拥有无限寿命，靠时间积累修为，在隐居/江湖/宗门/魔道/副本五条路线中做出抉择，走向不同结局。

**核心玩法**（原版，已重构入工程）：

- 时间即资源：岁月流逝被动涨修为，长生者打不死（重伤→耗费数十年恢复）
- 5 条主线：隐居苟命 / 江湖闯荡 / 宗门求道 / 魔道沉沦 / 副本冒险
- 回合制战斗：攻击 / 防御 / 逃跑，4 种怪物
- 3 个副本、7 件装备（纯数值）、10 成就、5 种结局
- localStorage 存档（现为 v2 带版本迁移）

**技术形态**：纯前端单 HTML（双击即玩，零依赖），已工程化为多文件源码 + Python 构建脚本。

### 扩展全景（用户 9 节方向，已映射批次）

1. **角色与成长**：六属性✅/抗性/命格天赋、功法秘籍（主动+被动+渡劫节点）、BUFF/DEBUFF 持续年数、记忆与阅历（关键事件解锁剧情）

3. **NPC 深度**：完整配置表（好感/立场/寿命/关系网）、多轮对话树、任务系统（主线/支线/循环/连锁，A 任务结果改变 B 任务）、人际关系网络
4. **战斗深度**：招式技能（灵力消耗/眩晕/吸血等特效）、敌人 AI（狂暴/召唤/回血/阶段 BOSS）、装备词缀随机掉落、伏击遭遇、团体战斗
5. **经济与交互**：完整背包分类（消耗品/材料/任务物品）、交易系统（地区物价/倒卖）、炼丹炼器（成功率/配方配置化）、凡俗王朝纷争
6. **叙事与 AI**：动态事件生成器（玩家状态驱动模板）、AI 辅助剧情（可选开关）、多周目继承、隐藏剧情/真结局
7. **模组生态**：模组完整规范（独立分发/依赖）、网页内可视化编辑器、版本校验/冲突检测
8. **多人雏形**：存档分享导出导入、简易道具/模组交换（无实时战斗）
9. **元游戏体验**：人物传记/回忆录导出、难度系统（简单/普通/硬核）、提示系统（日志检索/任务/可去地点）

- **数值配置化**：一切数值走 balance.js（后续 JSON 化），不写死公式
- **每批交付**：dist 可玩版 + 验证记录，批间可暂停调整
