# 面板可替换规范

> 版本：v1.0 | 日期：2026-08-15
> 目标：让「侧栏功能面板」随主题/文章类型动态替换，无需改 HTML 硬编码按钮。
> 适用：`index.html` 侧栏 + `js/novel.js`（数据驱动渲染）+ `js/data/novel.js`（主题配置）。

---

## 1. 设计原则

面板（侧栏功能按钮）由 JSON 配置驱动，不在 HTML 里写死每个按钮。主题切换时，按该主题声明的 `ui.panels` 渲染对应按钮；按钮的标签、图标、点击函数统一查 `PANELS` 注册表。

三层替换关系：

| 层 | 定义处 | 作用 |
|----|--------|------|
| 主题 | `js/data/novel.js` 的 `THEMES[]` | 皮肤 + 面板 + 多篇文章 |
| 文章 | 主题内 `novels[]` | 剧情文本 + 游戏名 |
| 面板 | 主题内 `ui.panels` + `PANELS` 注册表 | 侧栏功能按钮 |

---

## 2. 面板注册表（`PANELS`）

每个面板是一个条目，键为面板唯一 id，值为 `{label, icon, fn, desc}`：

```js
PANELS = {
  inventory:{label:"行囊",     icon:"🎒", fn:"sceneInventory", desc:"物品与装备"},
  skilltree:{label:"技能树",   icon:"🌳", fn:"sceneSkillTree", desc:"技能加点"},
  party:    {label:"伙伴",     icon:"🤝", fn:"sceneParty",     desc:"同伴/伙伴"},
  bestiary: {label:"图鉴",     icon:"📖", fn:"sceneBestiary",  desc:"敌方图鉴"},
  quest:    {label:"任务",     icon:"📜", fn:"questPanel",     desc:"任务面板"},
  npc:      {label:"拜访故人", icon:"💬", fn:"sceneNpc",       desc:"角色互动"},
  arts:     {label:"功法阁",   icon:"📖", fn:"sceneArts",      desc:"功法学习"},
  // ... 其余面板
}
```

规则：
- `fn` 必须是全局可调用函数名（字符串），点击时经 `sideGo(fn)` 调用。
- `label`/`icon` 决定按钮显示文本。
- 新增面板 = 在 `PANELS` 加一条 + 实现对应 `fn` 函数 + 在主题 `ui.panels` 里引用。
- 面板是**通用组件**，不绑定具体主题；主题通过 `ui.panels` 决定展示哪些。

---

## 3. 主题配置（`ui` 字段）

每个主题在 `THEMES` 内声明 `ui`，控制资源栏与侧栏：

```js
ui: {
  resources: ["life","realm","cult","hp","mp","stone","year","status"],
  attrs: ["constitution","soul","spirit","comprehension","heart","demon"],
  panels: ["inventory","arts","alchemy","faction","quest","npc","memory","novel","bio","hint","diff","share","mod"]
}
```

字段变更即生效，无需改 HTML：
- 增删 `resources`/`attrs` 项 → 资源/属性栏字段显隐。
- 增删 `panels` 项 → 侧栏按钮增删。

---

## 4. 渲染流程（`js/novel.js`）

`applyUi()` 每次主题切换时执行：

1. 读 `_THEME.ui`（缺省用通用默认值）。
2. 遍历 `.ufield`，按 `data-k` 是否在 `resources`/`attrs` 决定显隐。
3. 清空 `#sidebtns` 容器，按 `ui.panels` 顺序 + `PANELS` 注册表，动态 `createElement('button')` 生成侧栏按钮。
4. `🏠返回主线` 恒显（不属面板）。

`sideGo(fn)` 是通用点击入口：查 `window[fn]` 存在即调用。

---

## 5. 如何新增一个面板（三步）

1. **注册**：在 `PANELS` 加 `{label, icon, fn, desc}`。
2. **实现**：写对应 `fn` 场景函数（参考 `sceneInventory` 风格：`log()` 输出 + `addBtn()` 渲染选项）。
3. **引用**：在目标主题的 `ui.panels` 数组加入该面板 id。

示例——新增「锻造台」面板：

```js
// 1) PANELS 注册
"forge":{label:"锻造台", icon:"🔨", fn:"sceneForge", desc:"装备锻造"},

// 2) 场景函数
function sceneForge(){
 log("\n🔨【锻造台】你来到铁匠铺前。","gold");
 addBtn("锻造一把新手剑",()=>{ addItem("新手剑",1); log("获得【新手剑】！","green"); sceneForge(); });
 addBtn("离开",()=>mainStep0());
}

// 3) 主题 ui.panels 加入 "forge"
```

## 6. 资源栏与属性栏说明

- 资源栏（`resources`）：随行为高频增减、需常驻可视的数值（生命/魔力/金钱/年份/状态）。
- 属性栏（`attrs`）：定性描述、低频变化的体质（体魄/神魂/悟性等）。
- 当前 HTML 的资源/属性字段是**固定槽位**（`data-k`），主题只能选择显隐，不能新增字段标签。若需扩展字段名，需在 `index.html` 的 `.info-bar` 增补槽位。
- 转生主题应把资源栏收敛为生命/魔力/金币/年份/状态，属性栏收敛为力量/智力/敏捷三类。

---

## 7. 面板与剧情分离原则

- **主栏**（`#optbox`）：仅放「下一步剧情分支」选项（`story.js` 的 `mainStep0` 等）。
- **侧栏**（`#sidepanel`）：放「功能面板」入口（背包/技能/伙伴/任务等）。
- 功能类操作**不得**混入 `mainStep0` 的剧情选择里，保证剧情推进与功能管理解耦。
